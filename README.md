# 🧊 Okreni Obrni 3D

Dobro došli na stranicu igre **Okreni Obrni 3D** – interaktivne 3D puzle igre razvijene u čistom HTML-u, CSS-u i JavaScript-u.

## 🎮 O igri
**Okreni Obrni 3D** je izazovna logička igra optimizovana za računare i mobilne uređaje. Cilj igre je da rotiranjem slojeva 3D slagalice vratiš svaku stranu u njenu originalnu, jednobojnu poziciju. Igra sadrži sistem merenja vremena, praćenja poteza, čuvanje rekorda (`localStorage`), kao i sistem otključavanja novih vizuelnih tema.

* **Žanr:** 3D Puzzle / Logička igra
* **Tehnologije:** HTML5, CSS3, Vanilla JavaScript

## 🌟 Glavne karakteristike
* **3D Vizuelni Prikaz:** Dinamička rotacija 3D objekta pomoću miša ili prevlačenja prstom.
* **Sistem tema:** Otključavanje novih izgleda i tekstura rešavanjem nivoa.
* **Lokalno čuvanje:** Automatsko pamćenje poena, rešenih igara i najboljeg vremena.
* **Responzivan dizajn:** Prilagođeno za desktop i mobilne uređaje.

## 🕹️ Kako se igra
1. Pritisni dugme **„🔀 PROMEŠAJ SLAGALICU“** da započneš novu partiju.
2. Izaberi stranu koju želiš da okreneš preko kontrolnog panela.
3. Izaberi smer okretanja.
4. Rotiraj pogled na celu slagalicu prevlačenjem miša ili prsta preko radne površine.
